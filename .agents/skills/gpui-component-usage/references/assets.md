# Icons and Assets

This repository-local routing page keeps the relative link in the vendored
[`Icon`](components/icon.md) documentation usable without copying the complete
upstream documentation site.

- For workspace icon declarations, app-owned SVGs, runtime asset providers,
  and packaged application icons, use the `gpui-app-icon-usage` skill.
- For the `gpui-component` `Icon` and `IconName` APIs, read the vendored
  [`Icon`](components/icon.md) reference and verify the target app's actual
  icon enum and asset provider.
- The full upstream guide is available at
  <https://longbridge.github.io/gpui-component/docs/assets>.
