# Gupi 会话历史

- 状态：Done，已完成必要验证，可交付试用。
- 归属：Issue #220，Gupi 应用内的历史浏览、过滤和树折叠。
- 本文统一记录历史面板规则；[会话页面](README.md)只保留使用摘要。原生 RPC 边界不变，不实现同会话节点续聊。

## 已确定的产品规则

历史面板将展示方式、内容级别和列表分支范围分开：

| 维度 | 选项 | 范围 |
| --- | --- | --- |
| 展示方式 | 树 / 列表 | 全部 |
| 内容级别 | 简略 / 详细 / 全部 | 两种视图共用 |
| 分支范围 | 全部分支 / 仅此分支 | 仅列表，独立记住 |

默认保持列表、简略、全部分支。模式与范围属于窗口视图状态，关闭面板和切换会话后保留，不跨应用重启保存。

### 内容级别

- 简略：用户消息与 assistant 最终回答。
- 详细：在简略基础上包括中间说明、思考、工具调用与结果、失败、中断、压缩和分支摘要。纯思考和无正文工具调用不再提前过滤。
- 全部：在详细基础上包括空回复、设置变化、标签变更、自定义记录及其他 Pi 返回的会话 entries。标签继续附在其目标节点上，全部模式同时显示标签变更记录。

级别决定内容范围；树折叠只改变该范围内节点的呈现。被级别过滤的记录不计入可展开数量。分类使用共享语义描述，不按原始 assistant 角色判定最终回答。Pi 没有 final/commentary 字段，沿用同一父子链的后续助手/工具记录判定过程消息；原文与 parentId 不变。

### 列表与此分支

列表逐条呈现当前级别的记录，按 Pi 追加顺序从旧到新显示，不折叠过程。

仅此分支跟随正文正在查看的分支：无预览时使用 Pi 执行 leaf；预览其他分支时使用与正文相同的 preview_leaf 解析，展示根到该分支末端的完整路径，包括共同祖先，不只截到选中节点。共同祖先优先解析到执行分支，否则沿用最近追加后代的规则。浏览和范围切换都不修改 Pi 执行位置。

当原列表选中项不属于新范围时，优先定位正文预览目标或当前位置的可见代表。执行标记只在其可见代表确实属于列表范围时显示，不把预览分支末端伪装成执行位置。

### 树与过程折叠

树始终展示全部分支，按当前内容级别过滤，再建立紧凑纵向布局。

- 用户消息与 assistant 最终回答始终保留。
- 其余类型的普通过程链默认折叠，包括一条、两条记录的短链；压缩、分支摘要、错误和标签不单独构成免折叠条件。
- 显示根、分叉和叶子保留结构连接点；选中、预览和执行定位点保留。普通缩放下以最小类型标记表示，放大或悬停可读摘要，不能丢失树的连接关系。
- 折叠表现为端点间的虚线与内部节点数量，不增加伪造 entry。点击一次展开整段；展开和收起在过程段起点的连线上统一使用小箭头与数量，分别为向下和向上箭头。无常驻外框和长操作文字，悬停或键盘访问提供完整操作说明；实际命中高度为 24px。展开段旁以淡色括线标示范围，端点菜单同时保留。收起只隐藏未被定位的过程节点，选中、预览和执行节点继续显示；显示数量为实际可收起节点数，不因段内存在定位点而禁用整段操作。
- 被内容级别过滤的定位点映射到最近可见祖先；原始预览与执行 ID 不变。
- 内容级别变化后保留用户手动展开的 entry ID；返回详细/全部时恢复。历史快照中真正删除的 ID 才从展开意图中清除。
- 每个会话保留树的选择、平移、缩放和展开意图；切换视图或内容级别不重置相机，重排按可见节点锚定视口。新历史不主动执行查看全图。

### 操作入口

标题行按默认视图排列为列表/树，右侧为关闭按钮。视图切换保留明确选中态。第二行统一为轻量下拉：“内容 · 简略/详细/全部”，列表额外提供“范围 · 全部分支/仅此分支”。前缀使用弱化文字，当前值保持可读；宽度不足时按控件组换行，适配最小 240px 历史面板。缩放、查看全图和定位当前节点集中在树画布底部的紧凑工具栏，不再占用顶部第三行或分散在两端。所有控件使用中英本地化名称。

单击节点、Enter、方向键、正文预览、返回当前分支和原生 fork 延续已有行为。详细或全部中的设置记录没有独立正文消息时，允许选择并查看历史摘要，不伪造聊天消息。预览其他分支仍暂停普通发送并保留草稿。

## 数据、职责与刷新

- `state/history.rs`：三种内容级别、分支范围及可见祖先的统一投影。History 拥有原始 entries、leaf 和描述缓存；UI 不维护第二份 transcript。
- `state/history/nodes.rs`：语义分类、纯文本摘要及元数据描述；全部模式显示可辨认的本地化记录类型。
- `state/history/canvas.rs`：连续段识别、保护定位点、展开意图和显示树。
- `features/home.rs`：窗口级视图选项、会话级画布和正文预览；历史 revision 与内容级别共同决定画布输入刷新。
- `features/home/history.rs`：模式与范围控件、列表呈现。
- `features/home/history/canvas.rs`：相机、绘制、命中、菜单与键盘。真实历史 ID 用于裁剪失效的展开意图，级别过滤不删除意图。

分支范围只影响列表，不能进入树的内容缓存。正文流式刷新不反复重排已有历史；没有稳定 entry ID 的实时内容仍不增加临时树节点。相应的列表选择、执行和预览标记都从过滤后的行集合解析。

不新增依赖、RPC 命令、会话文件字段或持久化设置。

## 保留的树布局与交互实现

布局使用迭代式 Buchheim / Reingold–Tilford 紧凑树算法，固定逻辑间距；多个根通过内部虚拟根布局，虚拟根不计数或绘制。实现位于 `state/history/canvas/tidy.rs`，保留 D3 的版权和 ISC 许可声明。[D3 tree](https://d3js.org/d3-hierarchy/tree)、[许可](https://github.com/d3/d3-hierarchy/blob/main/LICENSE)

世界坐标与屏幕坐标统一采用 `screen = world × zoom + pan`。平移/缩放不重算树布局；按层索引查询可见节点和穿屏边。单子节点上下对齐，兄弟顺序稳定，纵坐标表示显示树层次。

- 滚轮与双指滚动平移；空白区拖动、空格拖动平移。
- pinch、缩放按钮和修饰键滚轮缩放，围绕指针或视口中心保持锚点。
- 缩放范围 0.001–4，按钮每次乘除 1.2。小于 0.65 显示点，正常显示类型 icon，从 1.25 起按空间附摘要；选中/悬停节点从 0.65 起优先显示摘要。
- 折叠线命中宽度为 24px 屏幕逻辑像素，按曲线距离判定，节点优先于边。拖动不误触展开。
- tooltip 延迟 450ms；平移、缩放、切换会话或目标失效后取消旧 tooltip。
- 根到所选节点的路径高亮，实际执行位置保持独立标记。
- 同一纵向过程链的摘要优先使用同一侧，按可用宽度截断；侧边空间或避让不足时放在上下方，不因相邻摘要竞争空间而反复左右切换。过程折叠控件独占连线间隙，不挤占节点摘要。
- 首次打开定位执行位置的可见代表；重开保留会话视口；空投影显示空状态。

## 验证结果

2026-09-12：`cargo test -p gupi history --locked` 通过 24 项；Gupi 构建、全目标 Clippy、格式与差异空白检查通过，中英文键与参数对齐。回归覆盖三级内容、完整分支路径、过程折叠往返、定位点保护、实际收起数量、跨内容级别保留展开意图，以及摘要同侧排布和碰撞时的纵向回退。

原生隔离模拟会话确认：240px 面板中“内容／范围”轻量下拉可用，级别和分支范围切换正常；默认列表在前，树与列表共享级别。过程段的向下箭头与数量可展开，展开后出现同位置的向上箭头与数量，淡色括线标示展开范围。32 条过程在 144% 缩放下的摘要优先同侧排列，小箭头控件不遮挡摘要；鼠标点击向上箭头＋32 后恢复为展开入口。此前的定位保护场景确认：选中段内思考节点后收起其余过程，思考、用户消息和最终回答仍保持可见；切到简略再回详细保留手动展开意图。
