# 临时窗口、全局快捷键与托盘

归属：[#221](https://github.com/suxiaoshao/gpui/issues/221)，父 Issue #217。设计与实现更新：2026-09-18。

已按确认范围接入临时多会话、系统快捷键、模板任务、附件、托盘与手动清理。使用方式见 [Gupi README](../../../README.md)。本文保留产品契约、实现分工和验证边界；不新增保存、OCR、自动清理会话/工作目录或项目设置。窗口自身按下述方案延迟回收，与数据清理无关。

当前已确认的应用侧实现已完成，剩余输入框改造见[输入框接入计划](composer-resources.md)：按用户 2026-09-18 决定，等待 [InputGroup #3042](https://github.com/longbridge/gpui-kit/pull/3042) 与[原子内联标签 #3113](https://github.com/longbridge/gpui-kit/pull/3113) 均进入兼容的 gpui-kit 正式版本，再升级并接入。共用外壳、Skill 填入正文、标签编辑、模板附带文件引用处理及可选 `@` 文件入口统一暂缓，不提前使用 Git 依赖或单独推进 Skill 行为。待确定项在恢复时讨论；原生交互与 Windows 尚未覆盖的验收见下方验证记录，两类剩余内容均汇入[总待处理文档](../../../../../docs/dev/issue-217/follow-ups.md)。

临时窗口的配置、样式与显隐差异见[Jaco 对照文档](temporary-window-comparison.md)。窗口配置（PopUp 类型、ModalPanel 等级，创建及每次显示时设置）、页面布局与显隐回收已按 Jaco 对齐；会话仍由 Global 持有，不落盘规则不变。

## 已确认行为

- 一个临时窗口承载多个独立会话，可新建、切换和并行运行。会话数据和 Pi 生命周期由 Global 持有，不依赖窗口；允许窗口销毁后重建，不能因此停止任务或清空会话。按 Jaco：失焦、再次召唤或关闭时隐藏，隐藏后 600 秒销毁窗口，重新显示取消回收；下次召唤从 Global 重建视图。
- 独立召唤器不附加模板、不取词、不发送，恢复当前会话与草稿；再次按键切换显示/隐藏。Esc 先交给弹窗/候选列表，再停止运行或隐藏空闲窗口。
- 打开临时窗口不等待 Pi 环境检测，也不自动回退主窗口。首次检测期间在窗口内显示准备状态；失败提供重试和设置入口，复用应用已有的配置与 Pi 检测。检测通过后在原窗口创建会话视图；已有会话不因后续检测被遮挡。原生窗口创建或显示失败时释放本次前台目标记录，避免后续回填使用旧目标。
- 模板任务有稳定 ID、名称、启停开关、键位、已有 Pi 命令模板、输入来源，以及可选的模型与思考等级。任务属性用预填弹窗，键位继续行内编辑；每项都是独立 SettingItem。
- 输入来源为选中文字、剪贴板、选中文字为空时回退剪贴板。macOS 使用辅助功能取词并允许模拟 Cmd+C 回退，Windows 模拟 Ctrl+C。文件路径优先，其次图片、纯文本。
- 有输入时在目标会话直接执行；没有输入时打开该会话等待输入，首次发送应用已选模板。整段文本作为一个参数，不添加多参数表单；无占位符模板使用正文、换行和输入文本。
- 同一任务在取词、准备、连接、提交及运行期间不会重复执行；已有会话可恢复显示。不同任务互不阻塞，已完成任务再次触发创建新会话。
- 模型默认由 Pi 决定；显式覆盖先设置模型，再校验并设置思考等级。只修改本次实例，不修改其他会话或全局 Pi 默认。
- 临时会话不保存、不进入主窗口目录；不提供转存、保存快捷键或后台恢复。隐藏窗口与释放会话是两个独立操作。
- 每会话使用 `<Gupi data>/temporary-workspaces/draft-<id>/`。配置、日志不放进工具工作目录；该路径不是工具访问沙箱。
- 临时窗口可删除当前会话及其工作目录，忙碌时禁用，先等待目标 Pi 退出，再移到废纸篓。失败保留条目并提示；其他会话和引用的原文件不受影响。
- 设置中的“临时对话”只清理已释放目录。仍由应用持有的会话，包括隐藏窗口和空闲会话，均受保护；不按时间自动清理。
- 托盘提供临时窗口、主窗口、设置、退出。应用退出统一停止接收触发并收尾全部 Pi。
- 全局按键默认为空，用户自行绑定。“全部恢复默认”清除全局键位并保留模板任务定义。
- macOS、Windows 有实现；Linux/Wayland 不纳入本轮系统热键支持。平台代码与实机验证分开记录。

## 实现分工

| 位置（相对 `app/gupi/src`） | 职责 |
| --- | --- |
| `app/temporary.rs` | 应用 Global 持有唯一临时窗口、ConversationState、焦点恢复目标、600 秒窗口回收与清理任务 |
| `state/conversation.rs`、`conversation/temporary.rs` | 普通/临时模式、每会话实例和独立 cwd；临时模式跳过扫描与草稿持久化，以 `--no-session` 启动 |
| `features/temporary.rs` | 顶部搜索、可拖动双栏、临时会话列表及上下文菜单；搜索/输入焦点切换 |
| `features/temporary/startup.rs` | 临时窗口的准备/失败页面，观察共享配置与 Pi 检测，就绪后原地进入会话视图 |
| `features/home.rs`、`home/*` | 复用消息、输入、模型选择与扩展交互，临时空会话居中输入；不展示主标题栏、侧栏和第三列历史 |
| `state/shortcuts.rs` | 配置、系统键规范化、重复校验、模板参数保真 |
| `app/shortcuts.rs` | 主线程系统注册、事件桥接、按任务 ID 去重、异步取词与目标会话准备 |
| `features/settings/global_keys.rs`、`global_keys/editor.rs` | 全局键位逐项行内编辑，模板任务属性弹窗，独立模型查询实例 |
| `state/config.rs` | 新 `[shortcuts]` 与 `[[shortcuts.tasks]]` 接入原配置事务、字段合并、注册预检和失败回滚 |
| `foundation/attachments.rs`、`features/home/attachments.rs` | 附件读取/编码、选择/粘贴/拖拽与预览；提交复用原 prompt 流程 |
| `app/tray.rs`、`app/menus.rs` | 系统入口和语言更新；退出统一走 StartupView.quit |
| `crates/platform-ext/src/app.rs` | macOS/Windows 前台目标捕获与恢复；保留 Jaco 原接口 |

临时窗口列表沿用 List 的导航与虚拟列表，条目使用与命令面板一致的圆角选中背景和会话图标，不使用默认蓝色选中描边。搜索框、会话序号与底部操作显示实际绑定的键帽。底部收为随输入状态变化的发送/回填主操作，以及 Cmd/Ctrl+K 上下文操作面板；面板右下角锚定，分组操作、底部搜索，关闭恢复原焦点。快捷键沿用统一设置，新增临时对话分组。

设置仍是同一个快捷键页面：应用、会话、会话文件、全局快捷键、模板快捷任务。模板正文由已有“提示词”页面管理，不复制另一套编辑系统。临时对话清理位于通用设置。

任务编辑与主输入框共用 `features/composer.rs` 的输入容器和底部布局，模型/思考等级 Picker 位于输入框右下方。弹窗保留禁用的正文区域，隐藏附件和发送操作；不连接主输入框草稿或发送事件。Picker 提供按提供商分组的模型搜索与思考等级滑块，覆盖可分别恢复为 Pi 默认；只更新弹窗草稿，保存后生效。命令模板可清空重选，但保存仍要求选择模板。添加任务位于快捷键页面右上方，与恢复默认按钮并列，模板刷新使用下拉框旁的图标按钮。

### 会话和任务生命周期

```text
系统触发 → 取词/附件 → 创建独立临时会话 → 连接 Pi → 校验模板与模型
                                                    ↓
                                   无输入：等待输入 / 有输入：提交
                                                    ↓
                                           Pi 接受 → 运行 → 空闲

可见窗口失焦 / 再次召唤 / 关闭 → 隐藏 → 600 秒后只销毁视图
隐藏期间重显：取消窗口回收，按鼠标所在屏幕定位
窗口销毁 → 重建：保留 Global 中的会话与 Pi，不停止任务或清理目录
删除当前会话：空闲 → 关闭并等待 Pi → 移到废纸篓 → 新会话
应用退出：禁止新触发 → 取消准备任务 → 全部 Pi 收尾
```

任务准备由应用持有 Task；运行复用 `PiState` 和 `ConversationState`。结果按 InstanceId 和 session key 路由，切换窗口不改变投递目标。模型查询独立使用 `--no-session`，弹窗关闭时收尾，不修改主会话模型。

同一键位只注册到系统入口，不同时绑定为应用动作。全局键要求带 Control、Command/Windows 或 Alt，单段按键；与应用内现有绑定及其他全局键冲突时拒绝保存。注册失败或配置写入失败会报错并尝试恢复原注册。

### 模板与附件

Pi 占位符包括 `$1`、`$@`、`$ARGUMENTS`、默认值和切片。命中占位符的模板交回 Pi 展开；参数用 Pi 自身引号语义保留空格、换行、引号与反斜线。无占位符则取模板正文并追加输入，不把正文开头的 `/` 误派发为插件命令。先检查个人资源启用状态，再确认目标实例的 `get_commands` 来源和路径；缺失、禁用、同名冲突均提示。

普通文件只发送 `@绝对路径`，保留含空格/非 ASCII 的原路径，不复制附件、不预读全文。RPC 将它作为文本交给 Pi，模型按需读取；不宣称 RPC 会执行 CLI 的文件展开。

图片直接通过 `Prompt.images`，支持纯图片和图文。文件选择、粘贴与拖拽汇入相同集合；解码、缩放、编码在后台执行。最长边不超过 2000，base64 单图控制在 Pi 的默认 4.5 MiB 预算内，大图转 JPEG 并进一步缩放；原文件保持不变。发出前检查模型 image 能力，添加时检查 Pi 的 `images.blockImages` 设置。

发送等待 Pi 确认后才清空对应文字/附件；失败保留，扩展在等待期间写入的新草稿不被清掉。模板首次发送失败也保留模板关联。完整请求与聚合历史仍受 pi-rpc 32 MiB 帧预算约束，容量错误走原错误反馈，不丢图或无界提高预算。

### 清理边界

清理只处理应用临时根目录下 `draft-` 子目录，拒绝根/目标目录符号链接。批量枚举后在 UI 线程获取仍持有的会话目录，再后台处理其余目录；新会话不会被当作已释放目录。删除单个会话按固定 key 等待实例退出，过程不依赖之后选中了哪个会话。

临时 Pi 退出会丢失内存上下文，所以此模式禁用普通“重新连接”和磁盘恢复；不会把显示历史重发给新 Pi 来伪造恢复。

## 参考与取舍

调研基于本地 Pi 提交 `71dca871b` 和仓库内 Jaco 源码。

- Pi `packages/coding-agent/src/main.ts` 的 `SessionManager.inMemory` 支持 `--no-session`；RPC `set_model/set_thinking_level` 不传 persist，不写全局默认。
- Pi `src/core/prompt-templates.ts` 提供参数展开语义；RPC `get_commands` 含来源路径。命令模板不是独立临时会话插件，本实现直接使用已有模板资源。
- Pi RPC 不经过 CLI/read 的图片处理入口，因此 Gupi 在后台完成编码；不能把 RPC 接受图片等同于模型收到图片。
- Jaco `app/temporary_window.rs`、`features/temporary.rs`、`state/temporary.rs` 和 `features/conversation/resources.rs` 支持临时多会话与独立运行；采用应用所有权和按会话路由；采用失焦隐藏、600 秒窗口回收和召唤时定位的行为，不将窗口销毁等同于会话删除，也不引入 Jaco 数据库体系。
- Jaco `state/hotkey.rs`、`features/settings/shortcuts/{form_state,dialog}.rs` 提供系统热键和任务属性编辑参考；Gupi 复用自己的配置与 Pi 实例管理。
- `global-hotkey` 0.8.0 在 macOS/Windows 的注册必须在相应 UI 事件循环线程；通过 channel 回 GPUI，不把系统注册放到后台线程。[官方 API](https://docs.rs/global-hotkey/0.8.0/global_hotkey/)
- 社区 `pi-side-chat`/`btw` 面向附属问答和 TUI 浮层，不作为独立临时窗口依赖；不引入额外插件运行层。

### 回填与导航

操作面板的最后一项复用 `Stop` 动作，运行时显示“停止生成”，空闲时显示“隐藏”，共用可配置键位；不并列显示两行。临时“移到废纸篓”使用独立窗口范围的动作，默认 Cmd/Ctrl+Shift+Backspace，调用原有删除检查与执行路径。回填默认 Enter，输入控件保留发送和输入法优先级；修改/清空绑定会撤销旧 Enter 回填，键帽从当前映射读取。面板打开时也可执行已配置的操作快捷键。

普通新建入口复用没有消息且未绑定模板的健康草稿，保留输入与附件；报错、准备失败或 Pi 实例已退出的会话不会被复用，仍保留供查看和删除。没有可复用草稿时创建新会话；模板任务仍调用独立创建入口。临时会话按创建顺序展示，数字快捷键以过滤后可见列表为准，1…8 对应前八项、9 对应最后一项。

回填使用当前执行分支最近一次成功停止的 assistant 正文，排除思考、工具调用、失败或中断内容；有 final-answer 分段时仅取最终段。面板只按会话内容版本缓存可用性，执行时重新校验并提取文本。业务状态仍由 ConversationState 持有。

窗口 Global 保留一次回填任务，先写入剪贴板，再隐藏与激活原应用。macOS 定向投递 Cmd+V 到记录的 PID；Windows 校验原 HWND 后发送 Ctrl+V。系统权限、焦点和剪贴板均在发送前检查，重新召唤使旧回填失效；不会发送 Enter 或执行目标应用中的内容。失败保留文本并提示，跨应用按键送达不等同于目标编辑器接受文本。
