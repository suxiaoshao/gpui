# 会话快速打开

状态：已实现，待用户体验。默认 Cmd+P（Windows/Linux Ctrl+P），依赖[本地动作路由](actions.md)。

## 交付契约

复用现有会话目录和搜索能力，搜索并打开一个历史会话/已保留草稿；先核对现有弹层能否直接作为快速打开入口，不另建重复索引或第二套目录缓存。空查询的排序沿用目录已有规则。

候选显示会话标题与项目来源，键盘上下选择、Enter 打开、Esc 取消。仅浏览候选不启动 Pi，不改变当前会话或草稿；确认后走已有会话打开路径。切换查看不停止其他会话的任务。

目录发现/扫描/失败沿用已有状态。它是会话快速打开，不搜索所有会话正文，也不承接 Cmd+F。现有侧栏搜索入口与此功能共用同一行为。

## 现有基础与实现归属

`features/home/palette.rs` 使用 Dialog + CommandState + CommandItem，宽度 560px。候选来自 `ConversationState::infos()`，搜索关键词包含 cwd 和 first_message，确认回调调用 `open`。因此在现有能力上完善键盘入口、来源呈现和状态即可，不需要全新搜索服务。

`infos()` 将目录会话与运行中的本地会话/非空草稿合并，按 activity 倒序、key 次序稳定排序。未落盘且没有内容的空页不作为候选；本次保持这条现有规则，不引入最近访问排序或持久化 MRU。

## 候选与状态

| 状态 | 呈现与操作 |
| --- | --- |
| 首次目录发现/扫描，无已有结果 | 显示沿用的加载进度；不是“没有匹配” |
| 有旧目录，正在刷新 | 旧候选仍可浏览；显示刷新反馈，确认时再次校验目标存在 |
| 目录读取失败，有旧结果 | 保留旧结果和错误/重试入口；不因失败启动任意历史会话 |
| 成功且目录为空 | 显示暂无会话，与搜索无匹配区别 |
| 查询无匹配 | 显示无匹配，可编辑查询或取消 |
| 确认候选 | 以会话 key 重新查找，仍有效才调用现有 open；目标已移除则保留弹层并反馈 |

标题为主行，项目名/路径为来源辅助信息；同名标题需可区分。长路径截断但可读到必要来源。关键词保持 title、cwd、first_message 的元数据语义，不读取所有 JSONL 正文用于搜索。

候选更新与键盘焦点归 UI owner；数据权威仍是 ConversationState。面板打开时保存 key 顺序，目录更新仅更新原行元数据并追加新 key；已移除项禁用，确认时再查找 key，避免旧行号对应到另一个会话。

进入面板不打开 Pi；选中行移动不切会话。Enter 确认后按当前 open 行为切到目标页并显示该页加载反馈；取消不影响原草稿。原项目收起/展开与会话可见性遵循已有打开流程，不引入一套面板专用选择状态。

## 最小验收

- Cmd/Ctrl+P 与搜索按钮共用入口；上下、Enter、Esc 可完成一次打开/取消。
- 同名会话可凭项目区分；非空草稿可找到；空白无内容页不膨胀列表。
- 列表打开期间目录更新/目标移除，不因旧索引误开另一会话。
- 移动候选/取消不启动 Pi；确认走原加载流程，原会话运行和草稿保留。

来源显示和空状态属于本部分实现；中文输入和键盘总体路由由 actions.md 承担，避免为同一机制重复写多套测试。
