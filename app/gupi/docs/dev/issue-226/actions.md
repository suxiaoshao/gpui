# 本地动作与快捷键路由

状态：Implemented。快捷键路由及已有默认键的按钮、侧栏、图标和面板提示已接入。范围与研究见[总览](README.md)，验证边界见 validation.md。

## 交付契约

设置、新建会话、输入焦点、左右侧栏、刷新当前会话/目录、模型选择和停止等操作，菜单、鼠标、快捷键复用同一业务处理。Cmd+N 为新建，Cmd+R 与顶栏手动刷新统一调用[刷新重连](reconnect.md)，重新启动当前 Pi 并恢复会话。内部自动快照刷新保持原有轻量查询。

普通输入、扩展交互、选择器、侧栏、画布各自处理局部按键；弹层先处理 Esc，避免继续传播导致意外中止。保留原生文本编辑和输入法；不通过快捷键引入新的停止期间发送限制。运行中/加载中启用条件复用现有状态。

依赖：当前 Gupi 业务入口、实际 gpui-kit 的 action/key context 能力；无需等待 question 组件，扩展交互视觉不在本部分重做。

## 首轮动作表

主修饰键为 macOS Cmd、Windows/Linux Ctrl。实际 gpui-pre 支持 secondary；下表默认键已确认，见[决定清单 C-08](decisions.md)。键位不必暴露为用户可编辑配置。

| 动作 | 默认键 | 可用范围 | 执行依据 |
| --- | --- | --- | --- |
| 设置 | 主修饰键+, | 应用已有设置入口可用时 | app::menus / app::show；设置表单已有行为不变 |
| 会话快速打开 | 主修饰键+P | 主窗口，有目录或可展示加载状态 | quick-open.md |
| 统一命令面板 | 主修饰键+Shift+P | 输入、侧栏、历史区域均可用；设置/启动页只提供适用应用命令 | command-palette.md；Pi 候选按可见会话就绪状态加入，模态交互优先 |
| 新建会话 | 主修饰键+N | 非退出阶段；没有阻止切换的模态操作 | new_draft，沿用项目与草稿规则 |
| 输入焦点 | 主修饰键+L | 当前普通/扩展输入可用时 | 聚焦实际可见输入；select/confirm 聚焦可用选择控件 |
| 侧栏开关 | 主修饰键+B | 主窗口 | 复用 show_sidebar 与布局保存 |
| 历史面板开关 | 主修饰键+Alt+B | 当前历史入口可用时 | 复用既有历史开关和预览状态 |
| 刷新当前会话 | 主修饰键+R | reconnect.md 定义的允许状态 | 新增重连动作，不能直接绑定旧 refresh |
| 刷新目录 | 主修饰键+Shift+R | 非退出阶段，沿用扫描排队规则 | 目录刷新，不重连 |
| 模型/思考弹层 | 主修饰键+Alt+/ | 现有模型选择入口可用时 | 复用 Picker 与模型变更门禁 |
| 停止当前运行 | Esc | 无更内层取消对象，当前普通会话已有可停止操作 | 原有中止入口，不新增取消机制 |
| 应用退出 | macOS Cmd+Q，其他平台沿用菜单 | 应用级 | 现有受控退出；不映射为空输入 Ctrl+D |

选择目录、聚焦侧栏、重命名、移到废纸篓、复制回答等先复用现有菜单入口；统一面板的本地动作清单以 command-palette.md 为准，明确区分应用与当前会话操作；关闭窗口、隐藏/最小化/全屏先保持现有原生行为。研究总览中的备选不要求全部在首轮绑定。

## 路由与所有权

应用级设置/退出留在 app；统一面板根据可见页面取得会话上下文，当前会话操作路由到 ConversationState。普通 composer 局部处理 / 触发，随后交给同一个面板；面板获得焦点后仍保存来源上下文。PiState 只管理实例。可用性查询与真正执行使用同一业务检查，不能依赖按钮 disabled 就跳过状态层检查。

界面栈按当前焦点消费事件：输入法候选/文本编辑 → 当前选择器或对话框 → 扩展交互区域 → 主窗口会话动作。这里是路由目标，不新增手工复制系统 IME 状态；沿用 GPUI/输入组件实际事件机制。

- 输入组件处理中文组词、复制/剪切/撤销，不因添加主窗口 handler 丢失。统一面板 Enter 执行当前选中项，Pi 候选只提交一次，本地候选执行 action/打开控件；无候选时提交完整输入，不区分搜索词/命令文本，不吞掉 Enter。Tab 只补全 Pi 命令到输入框，不执行。手动输入和补全后编辑行为相同，完整规则及 Esc 持续抑制重入见 command-palette.md。
- Esc 关闭最内层补全、面板或取消扩展请求后停止传播；下一次 Esc 是否中止取决于新的实际上下文。命令候选因 Tab 完成或光标进入参数而收起时，保持命令输入焦点，不调用主动退出的持续抑制逻辑；回改命令名可重新展示候选。
- Cmd+P 在已打开的快速打开面板里聚焦现有搜索框；Cmd+Shift+P 聚焦已有统一命令面板，不叠第二份。快速打开与命令面板切换时先关闭旧面板，再开新的；不越过其他功能的确认/编辑对话框。
- 两个命令入口均捕获打开时的页面、目标 key/binding 与原焦点；执行前再校验，切页、切会话或 binding 改变时关闭旧面板。来自 / 的文字只用于初始化独立的命令输入，不同步、不回写正文，也不增加草稿版本校验。新建/快速打开动作自身可正常切换目标。
- 收起包含焦点的侧栏后回到可见主输入；面板取消优先恢复先前仍有效的焦点，否则回到当前可见输入。
- 历史画布局部 E、0、方向键和 Space 保持局部语义。一次按键不能同时执行画布操作与窗口动作。

## 快捷键提示与入口一致性

用户已要求补齐可见入口的键位提示。这属于现有动作路由工作的完善，不另建独立功能计划，也不为没有键位的动作新增默认键。

### 当前入口

| 可见入口 | 提示来源 |
| --- | --- |
| 顶栏侧栏、新建、刷新当前会话、历史按钮；侧栏搜索 | tooltip_with_action 关联对应 Run action |
| 侧栏顶层新建、设置、刷新目录 | 行尾 Kbd，设置查询 menus::ShowSettings |
| 模型/思考与停止按钮 | 操作名称、当前状态和对应 action 的快捷键 tooltip |
| 统一命令面板，含设置/启动页 | 查询真实 action/context；设置与退出分别查询 menus::ShowSettings / menus::Quit |

项目行新建继续使用该项目 cwd，不标注目标不同的 Cmd+N；模型列表刷新不标注重连快捷键。无默认键的动作不虚构提示。

### 统一展示规则

- **图标按钮、紧凑按钮**：tooltip 显示操作名称和独立 Kbd，保留无障碍名称；不把长键位文字塞进图标或按钮主体。
- **侧栏文字操作行**：右侧显示弱化的 Kbd；空间不足或折叠成图标时，tooltip 仍提供完整操作与键位。名称优先保留，不挤压成难以辨认的内容。
- **菜单与命令面板**：在已有右侧辅助区显示真实键位；沿用原生菜单/组件支持，避免同一项出现两份提示。
- **键位来源**：查询实际 action（包括参数）和正确 context，通过 Kbd 格式化。普通窗口动作使用目标业务上下文；输入、历史画布等局部键必须保留作用域，不能展示成应用全局键。
- **实际目标一致**：只有快捷键与点击的操作、目标相同时才显示为同一入口。项目行“新建”使用该行 cwd，Cmd+N 使用当前会话项目；不能给所有项目行无条件显示 Cmd+N。其他非当前会话的行操作同样校验目标。
- **同名不等价**：模型弹层内刷新只是重新读取模型；顶栏 Cmd+R 会重连 Pi。不能因为都是刷新图标，就复制 Cmd+R 提示。
- **无绑定不虚构**：改名、删除、选择目录、显示主窗口等当前无默认键的操作保留普通提示，不为填满列表擅自注册快捷键。仅用于状态或统计的图标不添加动作键。
- **可用性一致**：有绑定但当前禁用的动作可保留键位以便发现，同时说明禁用原因；提示不能让键盘绕过真实门禁。普通提交、命令候选执行与扩展回答的 Enter 提示随实际输入上下文显示；Pi 候选同时提示 Tab 补全；无候选且可提交时提示 Enter 发送，无会话或当前不可提交时反映实际状态。
- **维护成本**：locale 保存动作名称和必要说明，不维护另一套 Cmd/Ctrl 字符串表。修改绑定后，相应 tooltip、侧栏和菜单提示从同一来源更新。

### 组件能力与实现归属

当前 gpui-component 已提供 Button::tooltip_with_action、Tooltip::action 和 Kbd::binding_for_action；本次不需要依赖升级。前两者关联动作以显示键位，不替代按钮点击处理，也不自动为业务函数注册 action。

优先让现有按钮和键盘共用动作处理/业务门禁，再为提示关联实际绑定。对于 Run 包装到 menus 动作的情况，使用实际绑定 action 查询或统一既有映射，避免复制一份手写快捷键表。侧栏自定义 navigation_row 可接收可选动作元数据并投影 Kbd，无需新建全局快捷键框架。

源码位置：features/home/titlebar.rs、navigation.rs、pickers.rs、composer.rs、palette.rs；features/startup/palette.rs；app.rs 与 app/menus.rs；实际依赖的 button/button.rs、tooltip.rs 和 kbd.rs。
