# Gupi

基于 GPUI Kit 的 Pi 桌面宿主。包含初始设置、配置恢复、主题/语言、窗口布局，以及基于 Pi 原生 RPC 的会话工作区。

开发导航：[总待处理文档：未完成项与能力边界](../../docs/dev/issue-217/follow-ups.md) · [开发计划索引](docs/dev/README.md)。

## 运行

```sh
cargo run -p gupi
cargo run -p xtask -- bundle gupi
```

默认配置：系统 config 目录下 `gupi/config.toml`；窗口和面板宽度保存在同目录 `state.toml`，非空的未发送草稿保存在 `conversations.toml`。
`GUPI_CONFIG_DIR` 可覆盖该目录，`GUPI_LOG_DIR` 可覆盖日志目录，`GUPI_DATA_DIR` 可覆盖应用数据目录；相对覆盖路径在启动时按工作目录转换为绝对路径。
macOS 默认日志为 `~/Library/Logs/gupi/gupi.log`，其他平台为系统 data-local 目录下 `gupi/logs/gupi.log`。

```toml
# pi_command 缺省时从应用继承的 PATH 查找 pi。
# pi_command = "/absolute/path/to/pi"
theme = "system" # system / light / dark
icon_theme = "classic" # classic / classic_gradient / color / color_gradient / pride / ukraine / ukraine_gradient
# light_theme = "preset:Default Light"
# dark_theme = "preset:Default Dark"
language = "system" # system / english / chinese / traditional_chinese / japanese / korean / german / french / spanish / brazilian_portuguese
```

首次缺少配置时，欢迎页后依次展示“语言与外观”“连接 Pi”“快捷键与通知”三个任务页；各页共享一个 `Form<AppConfig>`。语言、主题和图标立即预览，点击完成才创建配置；可保留默认、稍后配置 Pi，不要求检测成功。macOS/Windows 的临时窗口全局快捷键默认未设置（Linux 引导不显示该控件），回答完成默认后台通知，等待用户通知默认开启。已有配置不重新引导。语言使用可搜索 Combobox，主题以浅色、深色两组自适应单选卡片网格展示，分别保存选择。页面使用 240ms 缓入缓出横向过渡，尊重系统减少动态效果设置；具体主题与图标置于可展开的可选区域，悬停主题卡片显示完整名称。配置恢复不会读取或修改 Pi 凭据。
保存前重新读取配置，只将本次相对已加载设置修改的字段应用到最新内容，再用同目录临时文件原子替换；未修改字段保留磁盘最新值，同一字段以本次保存为准。
显式写回已应用配置使用完整已应用值并保留当前草稿；保存/重读失败保留内存与草稿，修正后可重试。配置损坏时仍提供备份并重置。
默认窗口为 960×740，最小为 800×600；旧的小尺寸记录恢复时扩至新下限，并按屏幕范围约束。窗口布局不可用时尝试删除 `state.toml`，使用默认窗口继续启动；退出时直接写入当前窗口数据，删除或保存失败只记录日志。

语言支持英语、简中、繁中、日语、韩语、德语、法语、西语和巴西葡语，缺失翻译回退英语。应用文案即时切换；macOS 原生文件选择等对话框在重启后使用所选语言，跟随系统时尊重系统语言，不修改系统的语言偏好。Windows 公共对话框跟随 Windows 显示语言。打包包含对应 macOS 语言资源与九种语言的 WiX MSI；`bundle --install` 默认使用英文 MSI，也可手动运行其他语言安装包。

同一配置目录只启动一个 Gupi，重复启动唤醒已有主窗口；不同 `GUPI_CONFIG_DIR` 仍可独立运行。`instance.lock` 由进程持有、退出时系统释放；`instance.json` 只是本机唤醒端点记录，下次启动自动替换，不含会话内容。
单实例初始化失败时，主窗口显示启动恢复页，提供具体错误、重试、打开配置文件夹和退出。重试成功后继续原有配置读取与恢复流程；取得目录所有权前不进入设置或会话、不修改布局或日志，也不启动 Tray 和 Pi。恢复页沿用可读取的窗口布局；无法联系已有实例不会绕过文件锁，退出恢复页不保存配置或布局。

应用菜单提供会话、编辑、显示、窗口和帮助命令，Windows/Linux 用应用内菜单栏显示相同入口；命令作用于当前窗口和焦点。帮助/关于提供文档、日志位置和复制基础诊断，诊断不含会话正文、凭据或环境变量。日志约 5 MiB 轮转、保留三个归档。系统辅助功能、通知和 Dock 角标权限的恢复指引与系统设置入口位于相应设置页。

外观页还提供七种应用图标主题：经典、经典渐变、Pi 彩色、Pi 渐变、彩虹、乌克兰和乌克兰渐变。经典沿用系统明暗外观，其余主题使用适用于亮暗桌面的有色背景。Pi 渐变按官方上方珊瑚、左下蓝、右下金的位置融合；乌克兰渐变在蓝黄之间加入亮青过渡。彩虹十格按行使用红橙黄、绿蓝、紫红橙、绿蓝，复用红、橙、黄、绿、蓝、紫六种纯色；不提供彩虹渐变。选择即时保存并更新应用内品牌标记，macOS 同时更新运行中的 Dock 图标。打包运行使用编译的 Icon Composer 资源，开发运行可回退到同源 PNG；恢复经典时恢复 bundle 图标。Finder、退出后的图标以及 Windows 任务栏图标仍采用打包默认。

常规设置分为通用、外观、通知、Pi、快捷键、插件、Skill、提示词和关于。侧栏搜索按字段筛选分类，Skill 页另有名称/说明搜索。语言与主题即时保存，相同有效值不重复应用或刷新窗口；Pi 路径单独提交，修改主题不会提交尚未保存的 Pi 路径。

快捷键页支持录制键位、确认保存、清空绑定与恢复默认，冲突先反馈。覆盖值写入同一份 `config.toml` 的 `[keybindings]`，例如 `new = "secondary-shift-n"`；留空取消绑定，删除覆盖恢复默认。按钮提示与菜单读取运行中的同一份键位表。全局快捷键与模板快捷任务也在本页独立分组，每项可录制、确认、取消和清除；系统键位支持 macOS/Windows，默认不绑定。Linux 尚无全局快捷键后端。全局键保存到 `[shortcuts]` 与 `[[shortcuts.tasks]]`，恢复全部默认清除键位并保留任务定义。

插件、Skill 与提示词只管理个人 Pi 资源：使用 `PI_CODING_AGENT_DIR` 或 `~/.pi/agent`，以及个人 `~/.agents/skills`，不扫描项目配置。包安装、单包更新和移除调用已保存并检查过的 Pi；资源启停保留 Pi 配置中的其他字段。自有 Skill、命令模板与 `SYSTEM.md` / `APPEND_SYSTEM.md` 显式保存正文，包内和外部注册文件只读。本地 Skill 登记路径，不复制或接管文件；删除自有资源只将所选文件移到废纸篓。已有会话需手动刷新。
资源目录首次显示时加载，重开设置复用结果；外部资源变更通过刷新按钮重新读取。保存既有 Skill/模板文件、启停或删除资源会定向更新，新增/注册资源及包操作仍重新发现资源。

设置组件的搜索选择修复与正式依赖接入情况见[设置开发记录](docs/dev/issue-231/README.md)；当前依赖版本以根 manifest 为准。

Pi 检查仅执行指定程序的 `--version`，从提交起使用 15 秒整体 deadline，覆盖排队、命令查找、创建进程和读取输出；stdout/stderr 各限制 16 KiB。失败或取消后释放 Child，由已启用的 kill_on_drop 和 Tokio 后台回收处理，不追加清理等待。查找与启动使用后台阻塞任务，应用内最多同时两项，取消后仍阻塞的任务继续占用名额直至返回；不启动交互式 shell，不安装 Pi/Node，不调用模型。
主窗口与临时会话只依赖已加载配置，不等待版本检查。创建会话后直接查找并启动 Pi RPC，连接期间限制输入和发送，失败在该会话内显示，不遮挡本地历史。设置页保留已保存命令与草稿命令的独立检查：首次显示 Pi/插件页面时按需检测已保存命令，后续复用同一命令的结果；草稿检查由用户显式触发；检查结果不决定会话界面是否可用。取消通过 Operation Cancel/Task Drop 停止等待并使旧完成链失效。
保存期间禁止修改表单；失败后保留草稿，仍用保存按钮提交当前内容。重试重新读取磁盘并取当前草稿，不重放旧提交。
macOS/Windows 关闭窗口隐藏，重新唤起恢复；显式退出取消两种 Pi 探测，等待已开始的配置提交，再保存布局，并完成应用级 PiState 的逐连接关闭后退出。GPUI 完成链由对应 Operation 或根视图字段持有；可能晚于取消返回的阻塞启动任务以有上限的名额和通道交接管理资源，不再回调 owner。

### 会话同步与刷新

启动时发现会话目录；外部 Pi/TUI 新增或修改的会话由用户点击“刷新会话目录”发现。普通任务结束、改名、复制和删除不扫描全部目录；切换已知项目不扫描，首次选择新项目只发现该项目的历史。Gupi 内部变化按来源和受影响区域合并同步，侧边栏复用项目分组，保留展开状态和滚动位置；后台会话变化不重建前台不变的消息与历史投影。删除后台会话保留当前页面；删除当前会话后清空选择并显示新建入口，不自动创建替代会话。

名称、思考等级和追加历史条目使用 Pi 事件同步。普通模型重试与摘要重试分别显示尝试次数、剩余等待时间和原因；倒计时只更新提示，归零后等待 Pi 的实际事件，界面不自行重试。运行计时也只更新过程标题；流式正文、Markdown 解析及折叠操作按受影响消息行更新尺寸。通知由应用统一投递，主窗口与可销毁的临时窗口共用来源会话。正在查看来源时直接显示已有待答/错误状态；前台其他会话收到可点击的应用内提醒；后台待答、最终失败和回答完成默认发送系统通知。每个新待答请求分别提醒，可关闭系统注意力提示；取消、重试过程和工具进度不发送完成/失败通知。系统通知使用通用描述，点击只返回已有来源，不自动重连、批准或发送；已解决、超时或失效请求的通知撤回。

每个有未读回答的会话计 1；待答、错误状态、插件提醒本身不增加数字。前台打开来源后清除未读，待答/失败业务状态仍保留。主/临时侧栏独立显示未读点，项目分组汇总数量；macOS Dock 和托盘标题显示总数，Windows 托盘提示和菜单显示同一总数。插件 info/warning/error 与压缩失败详情在来源“会话提醒”中保留多条内容，可展开、手动清除；这些临时提醒与本轮会话阅读标记不跨应用重启恢复。

macOS 托盘使用独立的透明模板图标，由系统适配菜单栏明暗；未读数字显示在标记旁。托盘菜单依次展示窗口入口、可用的会话状态列表、设置与退出，动态会话列表不改变底部操作的位置。Windows 保留应用图标。

通知偏好写入 `config.toml` 的 `[notifications]`：`waiting`、`failures` 和 `attention` 默认开启，`plugins` 默认关闭系统投递，`completion` 默认 `background`（另有 `off` / `always`）。macOS 系统通知需要应用 bundle 及系统授权；首次产生未读时单独申请 Badge 权限，授权完成后应用当前 Dock 计数，拒绝后不反复请求。Dock 跳动使用单次 informational 请求；系统权限与专注模式可能影响实际呈现。Windows 不使用 macOS 的 Dock 数字接口。

### 临时窗口与附件

在菜单/托盘选择“临时对话”，或在快捷键设置中绑定独立召唤键。窗口采用与 Jaco 一致的 PopUp / ModalPanel 配置，每次在鼠标所在屏幕居中显示。失焦、再次按键或关闭时隐藏，隐藏 600 秒后销毁视图；再次召唤取消回收或从 Global 重建，Pi 继续运行。顶部搜索临时会话标题，左侧列表可切换多个独立会话，右侧复用消息与输入组件。Cmd/Ctrl+F 聚焦搜索，搜索框上下键切换会话，Tab 在搜索和正文间切换，Cmd/Ctrl+N 优先跳转到已有未发送的普通新对话页，保留草稿和附件；没有可复用页面时才新建（模板任务仍独立创建会话，应用动作遵循用户快捷键设置）。Esc 优先关闭弹窗/候选列表，再停止生成或隐藏空闲窗口。

右下角保留主操作和“操作”入口，Cmd/Ctrl+K 打开当前会话的操作面板，底部搜索操作。可粘贴或复制最后完整回答、聚焦输入、选择模型、定位工作目录、删除会话、新建，以及随运行状态切换的“停止生成 / 隐藏”；右键菜单复用相同的工作目录和删除逻辑。在搜索框、会话列表或操作面板中，Cmd/Ctrl+Enter 仅复制回答并保留窗口。Cmd/Ctrl+1…8 选择当前搜索结果中的前八项，Cmd/Ctrl+9 选择最后一项；列表显示实际键位，会话按创建顺序排列，后台回答不会改变序号。“移到废纸篓”默认 Cmd/Ctrl+Shift+Backspace，仅作用于临时会话。面板所有操作均接入快捷键设置：临时专用动作在“临时对话”分组，共用的新建、模型、聚焦输入和停止/隐藏在原有应用或会话分组。回填默认 Enter，改绑或清空后旧键不再回填；面板键帽同步显示实际配置。

默认情况下，搜索框或会话列表按 Enter 回填当前选中会话的最后完整回答；对话输入框有文字或附件时 Enter 发送，文字为空或仅空白且无附件时 Enter 回填。生成中、没有完整回答、输入法组词中或附件仍在加载时不回填，Shift+Enter 换行。回填先复制文本，再隐藏窗口、恢复召唤前的应用并发送粘贴按键；macOS 需要辅助功能事件权限。权限或目标不可用时保留剪贴板并提示手动粘贴；隐藏期间重新召唤、目标焦点或剪贴板改变时不向其他应用继续注入按键。

模板快捷任务复用已启用的个人 Pi 命令模板，可选取词/剪贴板来源，以及本次模型和思考等级。取得输入后直接执行，没有输入时等待用户输入；同一任务运行中再次触发返回已有会话，完成后再次触发创建新会话。指定模型只作用于该会话。

临时会话通过 `--no-session` 运行，不出现在主窗口目录，也不保存草稿或模型上下文。工作目录位于应用数据目录的 `temporary-workspaces/draft-<id>`。临时窗口会话菜单可将当前空闲会话及工作目录移到废纸篓；通用设置可清理已释放目录，仍由临时会话持有的目录会跳过。当前版本不提供临时会话保存/转存。

普通与临时输入框均支持文件选择、粘贴和拖入附件。图片原始内容保存在系统临时目录，草稿只持有文件与元数据，发送时在后台读取并生成 Base64，通过 RPC 发送；不在 Gupi 中缩放或重新编码图片。缩略图与大图预览从同一份原图加载。图片文件由草稿、发送任务和已打开的预览共享，最后一个使用者释放后自动删除，关闭窗口本身不决定文件是否删除；选择图片不会修改或删除用户原文件。临时文件存储减少原始字节和 Base64 的常驻副本，不限制预览解码内存。模型相关的图片处理和限制交由 Pi 执行。普通文件发送 `@绝对路径`，不复制或删除原文件。Pi 确认收到后清空对应附件，读取或发送失败时显示错误并保留附件。

## 会话工作区

- 用户消息的图片与文字在同一个 `MessageContent` 中分开排列：图片以原始比例缩略显示，多图成组，文字独立放入气泡，纯图片不显示空文字气泡。点击图片打开铺满窗口的半透明遮罩预览，不带 Dialog 外框；附件显示名称，消息图片不显示通用标题。可缩放、滚动，点击空白、关闭按钮或按 Esc 关闭并恢复焦点；这些布局不改变 Pi 会话中的图文存储。
- 窗口顶部统一为单行：左侧原生窗口按钮及侧栏开关，右侧会话标题、会话菜单、刷新当前会话和历史开关。刷新保留已有正文，失败可重试；设置保留在侧栏底部与原生菜单。
- 左侧按工作目录组织会话，品牌行右侧搜索，下方新建；默认显示每组最近 5 条，保留当前项，支持目录选择、全目录搜索和刷新目录。默认 Pi 目录及已知项目配置的 sessionDir 会被发现；未知项目的自定义目录不扫描。
- 会话菜单提供重命名、路径操作、停止生成/结束运行，以及“移到废纸篓”。重命名统一使用 Pi 的 `set_session_name`；未连接的历史会话先启动正常 RPC 连接，再由 Pi 写入名称，不切换当前选择，成功后自动刷新侧栏。删除由 Gupi 管理：已有会话文件时，等待自身 Pi 实例退出、核对文件身份后移入系统废纸篓；尚未落盘的新会话（含 Pi 启动失败）按会话标识单独移除，不调用文件删除，也不影响其他未发送会话。删除当前项后清空选择，用户主动新建时才创建或复用会话；失败保留会话和草稿，不回退到永久删除。生成、加载或会话操作期间禁用重命名和删除。正文和树节点变更仍通过 Pi RPC 获取、执行。
- 正文展示 Markdown、工具/思考过程和最终回答，过程与工具分组可展开；单个工具点击后在详情弹窗中查看命令、文件内容、diff、输出和附加信息，并按分区复制。运行中详情持续更新，在底部时跟随输出，向上阅读或选择文字时暂停跟随。压缩前后消息保持正常顺序，压缩摘要点击后在弹窗中阅读，支持选择复制和复制完整原始 Markdown。历史定位只定位消息入口，不自动打开详情。关闭弹窗不停止执行，查看内容不新增 RPC 或重新读取磁盘文件。流式消息使用 MessageScroller，向上阅读时保持位置。
- 插件持久消息按 Pi 的 `display` 决定是否在正文展示：可见消息保留文字、图片的原始块顺序，支持复制正文和点击图片预览；隐藏消息仍保留在原始历史中。插件消息独立展示，不计为 assistant 最后回答，也不打断同轮工具调用与结果的关联。生成期间回读历史不会覆盖较新的实时输出、运行、队列或模型状态。
- 会话更多菜单、会话右键菜单和命令面板提供“会话信息”，临时窗口使用其操作面板入口。弹窗展示已有标题、Pi ID、工作目录、会话文件、当前执行模型与思考等级，以及 Pi 返回的累计用量、费用和消息/工具计数；统计包含会话文件的所有分支，不按预览分支重算。ID 与路径可复制，存在的文件/目录可显示位置；临时会话标记未保存，尚未取得的数据显示未知或读取中。查看信息不启动闲置 Pi、不新增轮询，按来源会话的既有事件更新。
- Enter 发送或 steer，Alt+Enter 提交 follow-up，Shift+Enter / Cmd+Enter 换行。每个会话保留独立草稿；项目选择位于输入框上方。普通 prompt 由每个会话独立持有提交 task：Pi 连接及初始会话状态就绪前可编辑输入，但发送按钮、发送快捷键和命令面板提交均不可用，也不暂存待连接后自动发送的请求。就绪后，从点击提交到 Pi 返回 prompt 结果期间保留当前文本，输入框只读但可复制，发送按钮禁用并显示 loading，键盘重复提交也被阻止。Pi 确认成功后清空对应输入并恢复编辑，不等待模型完成；提交失败保留文本并显示应用内错误提示，恢复发送以便重试。生成期间继续按 Pi 原生语义支持 steer/follow-up，扩展交互输入区可独立回答。底部工具栏左侧为累计 Token 用量，右侧为合并的模型/思考选择器、上下文圆环和发送按钮；空间不足时用量换行，扩展状态留在输入框下方。累计用量与上下文圆环各自提供独立详情。
- 模型与思考程度在同一弹层调整：紧凑页顶部为只读 provider 图标、模型入口和刷新按钮，下方为滑杆与档位文字；点击模型进入较宽的供应商分组搜索列表，选完同时更新 provider 并返回紧凑页。刷新读取当前 Pi 的模型和档位，保持选择。可用档位与实际选中值以 Pi 回读为准；滑杆松开、点击档位或左右键调节时提交，关闭不提交。切换模型并读取新档位期间禁止调节，无思考能力时显示说明，单一档位只读。
- 标准 select/confirm/input/editor 暂时替换输入区；支持扩展通知、status、文本 widget、标题提示和编辑器文本更新。后台请求只在来源会话显示等待状态。Pi 连接断开或被关闭后清除该进程的待处理交互、标题提示、status 和 widget，保留对话内容与输入草稿；成功 fork 时这些扩展界面随原连接转交给新会话。
- 每次启动进入空白新对话，项目默认收起；侧边栏和搜索展示所有已创建会话，包括没有消息的会话。新建入口优先复用当前项目没有消息记录的可用会话，不根据输入框内容决定是否复用；没有可复用会话时才创建。空白会话不写入草稿文件。
- 目录先发现文件，再以“已处理 / 总数”和进度条读取元数据；刷新保留旧列表，成功后统一替换，不切换会话或展开项目。读取失败直接结束本次扫描并显示错误，不发布部分结果。
- 打开会话先获取核心状态和历史，模型列表、思考档位、用量和另开会话选项分别加载与重试。附加数据失败不阻塞已有对话；修改模型或思考强度后读回实际值再恢复提交，档位读取只影响思考调节。
- 正文和历史面板在首次读取历史时显示 skeleton，失败后提供重试；刷新过程中保留已有内容。成功的空历史与新对话欢迎页分别呈现，模型初始化不会使新对话进入历史加载态。
- 新对话首次打开模型弹层会自动加载选项；模型刷新只读取模型与思考档位，不扫描侧边栏目录，也不加载历史、统计或另开会话选项。模型选项加载不会新增会话条目。切换项目时优先复用该项目保留的空白会话及连接，保留模型、思考程度和正在加载的选项；已有输入、对话内容或待处理交互的会话不会作为空白会话复用。尚未连接的草稿切换项目时继续携带已输入的文本。
- 左右侧栏按独立像素宽度拖动，互不挤压；宽度保存到 `state.toml`，窗口临时收窄不会覆盖偏好。会话侧栏使用组件的 200ms 完全收起动画，开关按状态显示展开/收起图标；暂不提供悬停展开预览。
- 右侧分支树按对话顺序从旧到新排列，最新记录在底部；彩色轨道的节点与曲线统一绘制，摘要固定对齐。超出 5 条轨道时可横向浏览并定位选中节点。
- 命令面板支持中文名称和 Pi 原始命令名搜索（如 model、/model、thinking）；选中本地项后打开现有 UI 或执行 action。tree/fork 打开会话历史供选择消息，export/clone/copy 分别导出 HTML、复制会话、复制实际执行分支的最后回答；compact 发起当前会话压缩，显示进度状态、支持停止，完成后刷新历史及统计，失败显示 Pi 错误。正文输入保持不变。同名插件候选独立保留，不拦截正文命令。
- 标题栏右上角可导出 HTML 会话，使用系统保存窗口选择路径，完成后通知文件位置。会话右键菜单和标题后的更多菜单提供“复制会话”：通过 Pi `clone` 复制当前执行位置，保留原会话，成功后切换到副本并定向更新目录项，新会话输入框为空。两项操作要求会话连接就绪且空闲；复制还要求已有历史节点。
- “会话历史”提供树和列表，共用简略/详细/全部三级内容。简略显示用户消息与最终回答，详细包含过程与摘要，全部进一步显示设置、标签和自定义记录。树默认折叠普通过程段，用户消息、最终回答及结构/定位点保持可见；切换级别后保留手动展开与视口。列表可只显示正文正在查看的分支，包含共同历史。预览保留实际执行位置和草稿，其他分支预览暂停普通发送；用户消息下方的复制按钮旁提供 fork 按钮，沿用 Pi 原生语义：从该提问之前另开会话，并将提问填回新输入框；历史面板仍保留 fork 入口。
- 画布将至少 3 个可收起的连续节点合为带数量的虚线；点击线条展开整段，段端点右键菜单可重新收起。缩小时显示点，正常显示类型图标，放大后在空间允许时附摘要。所选节点的祖先路径高亮，实际执行位置保留独立圆形标记。
- 画布支持滚动或拖动平移、pinch 或 Cmd/Ctrl 加滚轮缩放；工具栏提供缩放、查看全图和定位当前节点。方向键只移动选择，Enter 预览，E 展开所选节点下的连续段，0 查看全图，+ / − 缩放。首次打开定位当前节点；同次运行内按会话保留视口和展开状态，退出后恢复默认。

附件内容编辑、完整队列管理、同文件节点续聊和任意 TUI 扩展组件尚未接入。窗口名称及 bundle 标识继续为 Gupi / `top.sushao.gupi`。

## Pi RPC 所有权

[pi-rpc](../../crates/pi-rpc/README.md) 承载纯命令探测和单进程 RPC；应用保留探测 Operation 与错误文案映射。应用级 `state::pi::PiState` 管理多个 client、稳定运行实例标识及各自事件消费任务，不直接持有 Child，不复制请求等待表，也不缓存完整事件历史。

连接按当前可见会话创建或复用：进入新对话页面和主动打开历史会话时建立对应实例，核心就绪前显示加载状态；扫描目录、恢复后台草稿和打开命令面板本身不会批量启动 Pi。同文件复用连接，切换和隐藏窗口不终止后台会话；配置命令变更只影响后续连接。标准扩展请求由来源会话的临时输入区承接，提交/取消回复原请求。

统一退出先停止新建连接并取消尚未交接的启动任务，再逐个关闭已建立的 client。每个连接发送 abort，收到成功回应后关闭 stdin，等待 Pi 正常退出；整个优雅关闭共用 2 秒上限，提前完成立即返回。失败或超时释放 Child，由 Tokio 终止及后台回收。通信 consumer 保留到连接关闭；连接关闭与配置/布局保存均在 cx.quit 前完成。CloseReport 只记录实际观察到的退出状态，不承诺失败路径已同步回收；具体边界见 crate README。
