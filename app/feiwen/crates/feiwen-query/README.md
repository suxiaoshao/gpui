# feiwen-query

QueryView 聚合表单、高级条件、查询任务和结果表格。依赖 feiwen-data；OpenFetch 事件由 shell 处理。持久结果文本使用 SharedString，数据和显示排序分离。

```sh
cargo test -p feiwen-query
```

结果表格支持双击表头右侧分隔线，按当前可见行和表头拟合该列；它不扫描完整查询结果。受限和标签使用复合徽章，不参与文本拟合。自动拟合最多 45rem，保留表格原有手动拖动边界（默认 1200px）；不随滚动或数据变化在后台自动重新拟合，需再次双击以重新计算。

拟合每次最多读取 64 个可见行，每项最多 512 个 UTF-8 字节、整次最多 8KiB（含缓存命中和表头）。文本超限或预算耗尽时直接取自动宽度上限，不对剩余文本哈希或测量。缓存按文本、完整字体和字号区分，最多 512 项，更换结果时清空；字号变化后的拟合重新测量。
