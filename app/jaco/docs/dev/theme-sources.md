# Jaco bundled theme sources

Jaco embeds GPUI Kit JSON presets so they remain available without network access.

## Current snapshot

- Source repository: [longbridge/gpui-kit](https://github.com/longbridge/gpui-kit)
- Source commit: `382fc28feb2de118c7a523c1b3a22d43aacd2f04`
- Source directory: [`themes/`](https://github.com/longbridge/gpui-kit/tree/382fc28feb2de118c7a523c1b3a22d43aacd2f04/themes)
- Local directory: `app/jaco/assets/themes/gpui-component/`
- Inventory: all 21 upstream JSON files, copied byte for byte. Gupi embeds the same snapshot independently.

The historical Jaco tab-color overrides have been removed; tab colors now follow the upstream presets.
Matrix is no longer in the upstream catalog and is no longer embedded. An unavailable saved preset
uses the existing light/dark default fallback; application configuration files are not rewritten.
Material You and system-accent themes remain generated by the shared `app-theme` crate.

## Runtime theme application

Jaco and Gupi use `app_theme::apply_theme_config`. It applies the selected component theme and calls
`Theme::sync_base` so Base renderers receive the same colors. This synchronizes resize dividers,
scrollbars and rich-text defaults, including Markdown foreground, code background and highlighting.
Refreshing windows alone does not perform this synchronization.

The applications still depend on GPUI Kit 0.6.0. Updating this preset snapshot does not replace the
component dependency with the upstream Git checkout.

## Updating the snapshot

Copy the complete `themes/` inventory from a fixed upstream commit to both applications, update the
source commit and exact inventory checks, and verify that the installed dependency parses every
preset. Keep upstream colors intact. Validate the affected theme path and light/dark rendering;
there is no requirement to run an unrelated application audit.

## Verification

The synchronized 21-file catalogs (36 variants) were compared byte for byte with the source commit.
Both application builds and affected Clippy checks pass. Jaco's asset checks parse/register the
presets and retain Aurora gradients. A light/dark Base-color regression failed before the runtime
sync fix and passes after it. Native Gupi rendering was checked with Catppuccin Mocha: the resize
divider, Markdown text, inline code and syntax-highlighted code block use the selected theme.
