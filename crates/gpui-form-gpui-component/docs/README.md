# gpui-form-gpui-component documentation

These task-oriented guides describe the current `Form<M>` and typed-path
adapter API exported by the crate.

## Tutorials

- [README quick start](../README.md): create a form, bind and render an Input,
  show its feedback, and prepare the same form for submission.
- [User guide (English)](guide.md)
- [使用指南（中文）](guide.zh-CN.md)

The guides provide copyable total and dynamic recipes for Input, Integer,
Select, Combobox, Checkbox, Switch, options refresh, error handling, and a full
custom-component path for both controlled elements and stateful adapters.
