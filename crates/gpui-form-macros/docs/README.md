# gpui-form-macros documentation

## Library documentation

- [User guide (English)](guide.md)
- [使用指南（中文）](guide.zh-CN.md)

The guide covers `#[derive(FormModel)]`, generated `ModelForm` / custom
`#[form(state = ...)]` entity states, per-field `SCREAMING_SNAKE_CASE`
allocation-free schema constants that expose reusable typed lenses,
total/partial availability propagation through `within` and `item`,
descriptor-owned schema access, Garde selection, generic models, stable array
paths, static submit transforms, and compile-time diagnostics.
