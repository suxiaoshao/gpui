# Gupi 与 Pi 的职责边界收敛

状态：实现完成，相关构建与回归通过；原生预览外观未完成复核。范围为用户确认的全代码审查结果及图片预览同步，覆盖 `app/gupi` 与 `crates/pi-rpc`。

## 目标与归属

Gupi 负责输入与附件交互、预览、界面状态和连接生命周期。Pi 负责模型策略、扩展输入处理、可信配置加载及会话文件写入。GUI 不复制 Pi 当前实现中的模型限制，也不把配置元数据当作发送前的硬性规则。

本轮顺序为移除本地输入策略与目录过滤、统一 RPC 改名、调整传输背压、同步预览，最后验证受影响链路。没有会话文件迁移或应用配置迁移。

## 当前实现

| 内容 | 处理 |
| --- | --- |
| 图片 | 原始内容以临时文件快照保存，附件共享文件所有权与 MIME、尺寸、大小元数据；发送时后台读取并编码 Base64，预览按文件加载。最后一个草稿、发送任务或预览使用者释放后清理文件，不修改用户原文件。删除 2000px、4.5 MiB、64 MiB、JPEG 转换策略；临时文件不构成预览解码内存限制。 |
| 图片发送 | 删除本地 blockImages 合并和模型 input:image 拦截，Pi/扩展决定是否接收、转换或拒绝。错误保留草稿。 |
| 模型候选 | 直接采用 get_available_models；删除本地 enabledModels 匹配和重复信任判断模块及其 glob 依赖。 |
| 模板任务 | 使用当前连接 get_commands 判断模板是否可用，删除启动前本地目录扫描拦截；保留已确认的模板参数/追加文本行为。 |
| 资源创建 | 支持中文等文件名；仅拒绝路径分隔符、控制字符和非法文件名字符，防止越界路径；保留不覆盖已有文件。 |
| 会话改名 | 已连接时复用实例，离线时使用正常连接和扩展事件消费者；初始同步后 set_session_name。删除 GUI 的 JSONL 追加与 v3 写入门槛，不改变前台会话选择。 |
| RPC | 删除请求、响应和事件的固定字节预算；保留有界队列，事件满时暂停 stdout，消费后继续；关闭仍能响应。保留请求/写队列的并发容量、启动/关闭期限和 stderr 尾部。 |
| Pi 诊断 | SemVer 解析接受预发布和构建后缀；--version 仍只用于诊断，不是建立会话的门槛。 |
| 图片预览 | 保留 InputGroup 中 Attachment 卡片；仅点击后的预览采用 Jaco 的浮动文件名、独立关闭按钮和底部缩放胶囊。适配、滚动、捏合、快捷滚轮、Esc/空白关闭保持可用。 |

Pi 参考为本地 0.86.0 的 rpc-mode.ts、agent-session.ts、file-processor.ts 和 provider adapter：RPC 图片载荷无统一 2000px/4.5 MiB 规则，CLI/工具图片处理逻辑不能套到所有 RPC 输入上。

保留个人资源管理、包安装参数、会话文件删除的归属核对、发送确认后清草稿及 GUI 显示用截断。这些属于现有产品行为或 GUI 生命周期，不是模型输入限制。输入框资源标签与逐条队列操作仍按各自上游能力边界执行。

## 验证

- Gupi 全部 206 项回归通过，覆盖原始图片字节/尺寸、图片转发、临时文件共享和释放、原文件快照、读取失败重试、编码期间停止、Unicode 资源名及模型目录。改名 4 项回归覆盖离线连接、前台会话保留、文件缺失、初始同步失败及已有连接重试。

- Gupi 构建、Gupi/pi-rpc 全目标 Clippy（`-D warnings`）、格式和差异检查通过。
